# Пчелна ферма „Три слънца“ — уебсайт

Статичен представителен сайт (една страница със секции-котви). Без билд стъпка —
отваря се директно: `index.html`.

## Структура

```
WebSite/
├── index.html          — цялото съдържание (всички секции)
├── css/style.css       — стилове (палитрата е в :root променливите най-отгоре)
├── js/main.js          — мобилно меню, активна секция, reveal анимации, броячи, лайтбокс
└── images/
    ├── logo.png        — емблемата (ползва се и за favicon)
    └── gallery-1..6.svg — временни илюстрации за галерията
```

## Какво да смените с реални данни

- **Телефон и имейл** — в секция „Контакти“ в `index.html` са примерни
  (`+359 88 000 0000`, `info@trislantsa.bg`). Сменете ги и в `href="tel:..."` / `href="mailto:..."`.
- **Числата в „Пчелинът“** — 80+ кошера, 15+ години и т.н. са примерни
  (атрибутите `data-count` в `index.html`).
- **Снимките** — заменете `images/gallery-*.svg` с реални снимки (jpg/png, най-добре 4:3)
  и обновете `src` и надписите във `figure` елементите на секция „Снимки“.
- **Картата** — iframe-ът сочи търсене „Кичево, Аксаково, Варна“ в Google Maps;
  при желание го сменете с точния пин на пчелина (Google Maps → Share → Embed a map).

## Хостинг

Всеки статичен хостинг върши работа — качват се файловете както са
(shared hosting, GitHub Pages, Cloudflare Pages и т.н.).

работи с резервните системни шрифтове.
